# Nik Studio - example script
#
# One scene a line. Blank lines space it out. A line starting with #
# is parked - it stays here but is not made.
#
# Do NOT describe Nik or the art style here. Those are set once, in
# CHARACTER and STYLE at the top of cell 2, and are put in front of
# every line automatically - which is the only thing keeping him the
# same boy from shot to shot.
#
# What each line should say, in this order:
#   1. ONE thing he does. Not three. Something a camera could film.
#   2. Who else is in the shot, and what they are doing.
#   3. One small piece of background life - flowers nodding, leaves
#      swaying, clouds drifting - so the world is not frozen.
#   4. "the camera does not move", unless it genuinely should.
#
# Anything you leave out, the model invents. That is how the puppy
# melted the first time.
#
# Avoid: turning or spinning on the spot (the face rotates away and
# comes back wrong), and more than one action in a line.
#
# colab/script_prompt.txt is the brief to hand a language model if you
# would rather it wrote these for you.
