================

DRIVE MEIN SIRF YE
------------------
      My Drive / NikStudio / Mixamo /   <- character pack, unzipped

Bas. nik_blender.py aur from_mixamo.py ab Drive mein NAHI chahiye -

CHALANA
-------
NikStudio_Rigged.ipynb kholiye. Ek hi cell hai. Chala dijiye.

Blender khud install ho jayega (~2 min pehli baar).
Character khud chun liya jayega.
Nik.blend khud ban jayegi.
3 clips ban jayengi.

Kuch bhi bharna zaroori NAHI hai.


AGAR KUCH BADALNA HO
--------------------
Cell mein sabse upar settings hain:

  CHARACTER = ""       khaali = khud chunega. Pack ka khaali putla
                       (BaseCharacter) aur zombie/knight/ninja apne
                       aap chhod diye jaate hain. Koi aur chahiye to
                       naam ka hissa likh dijiye: "Casual_Male"

  MOVEMENTS = ""       animation library ka folder (neeche padhiye)

  FIRST_ONLY = 3       3 clips. Saari banane ke liye 0

  CHILD = 1.0          bachche ka anupaat. 0 = jaisa download kiya

  ENGINE               "BLENDER_WORKBENCH" = flat, tez, bina GPU
                       "BLENDER_EEVEE_NEXT" = accha dikhta hai, GPU on


MOVEMENT ACCHI KARNI HO TO (marzi ki baat, zaroori nahi)
--------------------------------------------------------
Ab agar koi movement pack mein nahi hai, to character KHADA NAHI
rahega - uske sabse kareeb wali movement chalegi:

      wave  nahi mili  ->  clap chalega
      sway  nahi mili  ->  walk chalega
      nod   nahi mili  ->  crouch chalega

Aur death, punch, sword slash kabhi nahi chalenge - wo bachchon ke
liye nahi hain, chahe aur kuch bhi na ho.

Ye kaam chalau hai. Asli movements chahiye to:

  1. https://quaternius.itch.io/universal-animation-library
     "Download Now" -> daam ke box mein 0 likh dijiye. Free hai.
     (quaternius.com par ISKA PAID version dikhta hai - wahan mat
     jaiye)

  2. Unzip kar ke poori folder yahan daaliye:
        My Drive / NikStudio / Moves /

  3. Cell mein:  MOVEMENTS = "Moves"
