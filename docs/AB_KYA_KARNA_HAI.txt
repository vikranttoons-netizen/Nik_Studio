AB KYA KARNA HAI - SIRF YE, AUR KUCH NAHI
=========================================

Aapko abhi 4 kadam karne hain. Bas. Neeche jo nahi likha, wo abhi
mat kijiye.

Animate wali notebook ko abhi HAATH MAT LAGAIYE. Uski baari baad
mein aayegi (Kadam 5, aur wo mai bataungi).


KADAM 1 - EK CHARACTER DOWNLOAD KIJIYE
--------------------------------------
Koi bhi pack NAHI chalega. Sirf wo chalega jisme DONO cheezein hon:

      character ka SHAREER  +  uski ANIMATION

Isliye seedha ye kijiye - quaternius.com ke search box mein likhiye:

      Ultimate Animated Character

Pack ka naam: "Ultimate Animated Character Pack"
50+ animated character, CC0 (free, commercial allowed), FBX format.

Download karte waqt FBX chuniye (.blend mat lijiye).

JO AAPKI SCREEN PAR DIKH RAHA HAI, USME SE KOI NAHI CHALEGA:
  All In One File          -> $3 ka hai, paisa nahi dena
  Bestiary Dungeon Monsters-> daraawne monster, bachchon ke liye nahi
  Downtown City MegaKit    -> sirf buildings, character hai hi nahi
  Universal Animation Lib 2-> sirf animations hain, character nahi

Quaternius par kuch cheezon par daam likha hota hai - wo "premium"
extra hai. Neeche free download ka button hota hai, wahi dabaiye.


KADAM 2 - ZIP KO DRIVE MEIN RAKHIYE
-----------------------------------
Download ek ZIP file hai. Use pehle KHOLIYE (unzip):

  Windows: zip par right-click -> "Extract All..." -> Extract

Ek folder ban jayega. Uske andar chhote folder honge - FBX, glTF,
Blend, OBJ. UNHE CHHEDNA NAHI HAI. Andar jaakar file dhoondhne ki
zaroorat nahi - code khud neeche tak dhoondh leta hai.

Ab Google Drive mein bilkul aisa banaiye:

  My Drive / NikStudio / nik_blender.py    <- maine bheji hai
  My Drive / NikStudio / from_mixamo.py    <- maine bheji hai
  My Drive / NikStudio / Mixamo /          <- ye folder banaiye

Aur us khuli hui (extracted) poori folder ko "Mixamo" ke andar
daal dijiye. Bas.

  - Folder ka naam "Mixamo" hi rakhiye, chahe file Quaternius se
    aayi ho. Naam sirf ek naam hai, code wahi folder dhoondhta hai.
  - Kisi file ka naam badalna NAHI hai.
  - ZIP file khud upload mat kijiye - kholi hui folder upload kijiye.
  - Upload mein waqt lagega. Poora hone dijiye.

PACK MEIN 50 CHARACTER HAIN - EK CHUNNA HAI
Code apne aap pehla (naam ke hisaab se) le lega. Agar aapko koi khaas
character chahiye, to notebook mein ye line bharaiye:

      CHARACTER = "Boy"

File ke naam ka koi bhi hissa kaafi hai. Khaali chhodi to pehla wala.


KADAM 3 - RIGGED NOTEBOOK CHALAIYE
----------------------------------
Colab mein kholiye:  colab/NikStudio_Rigged.ipynb

  Cell 1 chalaiye  -> Blender install (~2 minute)
  Cell 2 chalaiye  -> Nik.blend banega, phir 3 clips

GPU ki zaroorat NAHI hai. T4 bhi chalega.

Cell 2 chalte hi wo bata dega usne kaun sa character uthaya, aur
kaun kaun si movement us file mein mili. Wo line padh lijiye - agar
character galat lage to CHARACTER = "..." bhar kar, REBUILD = True
kar ke dobara chalaiye.


KADAM 4 - MUJHE BHEJIYE
-----------------------
Output / Clips / se jo 3 video banengi, wo mujhe bhej dijiye,
aur screen par jo "Movement: __" wali line aaye wo bhi.

Yahin ruk jaiye. Aage kya karna hai, wo mai clips dekh kar bataungi.


AGAR ATAK JAYEIN
----------------
"no character file found"  -> file Mixamo folder ke andar nahi hai
"no movements found"       -> pack mein animation nahi thi, dusra
                              pack lijiye
Kuch aur error aaye        -> screenshot bhej dijiye, jhelna mat
