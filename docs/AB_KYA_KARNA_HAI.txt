AB KYA KARNA HAI
================

Naya raasta: pehle SHEETS banti hain (character sheet + background
sheet), phir har scene un sheets se JOD kar banta hai.

Iska matlab:
  * Nik har shot mein BILKUL ek jaisa dikhega - kyunki wo ek file hai,
    model har baar naya nahi banata.
  * Scene ki picture banane mein ZERO GPU unit lagti hai. Sirf sheets
    banane mein aur video banane mein lagti hai.

ABHI KYA KARNA HAI (ek hi baar, sirf 3 picture banengi)
-------------------------------------------------------
1. Drive mein jaakar SIRF ye teen file DELETE kijiye:

        input / sheets / places / meadow_wide.png
        input / sheets / places / meadow_medium.png
        input / sheets / places / meadow_close.png

   (yahi wo teen hain jinmein galti se ek bachcha khada tha)

2. cast waali folder ko HAATH MAT LAGAIYE. Nik, puppy, kitten,
   duckling - sab rehne dijiye. Unka background ab use karte waqt khud
   kat jayega, dobara banane ki zaroorat nahi.

3. NikStudio_Animate.ipynb kholiye. Cell 2 mein upar ye do line aisi
   hi honi chahiye:

        RUN    = "sheets"
        SOURCE = "character"

4. Dono cell chala dijiye. Sirf 3 picture banengi, phir notebook khud
   ruk jayega aur likhega:

        Stopped after the sheets, on purpose

5. Output mein Sheets.jpg banegi. Wo mujhe bhej dijiye.

   Usme dekhna hai: teeno meadow KHAALI hon (koi bachcha na ho), aur
   camera zameen ke paas ho - upar se nahi, naqshe jaisa nahi.


TEEN GALTIYAN JO IS BAAR THEEK KI HAIN
--------------------------------------
1. Har jagah mein ek bachcha khada tha.
   Wajah: prompt mein "for toddlers" aur "child's eye level" likha
   tha. Model jo naam liya jaata hai wahi banata hai - negative mein
   mana karne se farq nahi padta. Ab jagah ke prompt mein kisi insaan
   ka naam ja hi nahi sakta, notebook khud rok deta hai.

2. Puppy ka aadha hissa kat gaya tha.
   Wajah: safed kutta safed background par. Ab saara cast MAGENTA
   (gaadha gulaabi) background par banta hai - bachchon ke gaane mein
   aisa rang kahin nahi hota, isliye kaatna hisaab hai, andaaza nahi.

3. Kitten aur duckling ka background nahi kata tha.
   Ab use karte waqt bhi kaata jaata hai, isliye purani sheets bhi
   khud theek ho jaati hain.


SHEETS KE BAAD (aage ka raasta)
-------------------------------
  sheets  ->  44 scene ki picture (ZERO GPU, sheets jodkar)
          ->  44 clip (Wan 2.2, yahan GPU lagti hai)
          ->  beat par cut + lyrics + gaana
          ->  Video + Short
          ->  gaane waali line par lip sync (Wan 2.2 S2V)

Sab model free hain aur monetise karne ki ijaazat dete hain
(Apache 2.0).


RUN KE TEEN SHABD
-----------------
  RUN = "sheets"     sirf sheets banao aur ruk jao  (abhi yahi)
  RUN = "drawings"   har scene ki picture banao aur ruk jao
  RUN = "video"      clip banao aur video kaato
  RUN = "final"      wahi video 1080p + vertical Short
