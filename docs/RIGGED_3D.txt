RIGGED 3D - AAPKO KYA KARNA HAI
===============================

Ye us raaste ka pehla kadam hai jahan character sach mein animate hota
hai - AI se nahi. Blender kholne ki zaroorat NAHI hai.


CHARACTER KAHAN SE LAAYEIN
--------------------------
Do shakl mein files aati hain, aur tool dono samajhta hai:

  (A) EK FILE, SAARI ANIMATIONS ANDAR   <- ye aasan hai
  (B) HAR MOVEMENT KI ALAG FILE          <- Mixamo aise deta hai


(A) CC0 CHARACTER PACK - koi account nahi, sabse aasan
------------------------------------------------------
Ye sabse seedha raasta hai. Ek file download kijiye, bas.

  quaternius.com          CC0, cartoon jaise character, animations
                          andar hi (idle, walk, run, jump, wave...)
  kenney.nl/assets        CC0, isi tarah ke pack
  sketchfab.com           filter: Downloadable + CC0

  CC0 ka matlab: koi licence nahi, koi naam dena nahi, kuch bhi
  kariye. Mixamo se bhi saaf.

Download ki hui .glb ya .fbx file seedha Mixamo folder mein daal
dijiye. Naam badalne ki zaroorat NAHI - file ke andar ke naam padhe
jaate hain aur hamare naamon se mila diye jaate hain:

     "Walk_Armature"  -> walk
     "Armature|Walk"  -> walk
     "Breathing Idle" -> idle
     "Samba Dancing"  -> sway
     "Clapping.001"   -> clap


(B) MIXAMO - agar khul jaye
---------------------------
Mixamo band nahi hua hai, par Adobe ne use saalon se update nahi kiya
aur unka support use "unsupported" kehta hai. Kabhi-kabhi down rehta
hai. Isliye ispar tikna theek nahi - par chal jaye to theek hai.

1. mixamo.com, free Adobe account (commercial use allowed)

2. CHARACTERS tab -> ek character -> DOWNLOAD
      Format : FBX Binary
      Pose   : T-Pose          <- ZAROORI, animation ke bina
   Naam: nik_character.fbx

3. ANIMATIONS tab -> har movement alag download:

      Mixamo par                   File ka naam
      -------------------------    --------------------
      Idle / Breathing Idle    ->  idle.fbx      <- ZAROORI
      Clapping                 ->  clap.fbx
      Waving                   ->  wave.fbx
      Jumping                  ->  jump.fbx
      Walking                  ->  walk.fbx
      Samba Dancing            ->  sway.fbx
      Pointing                 ->  point.fbx
      Sitting                  ->  crouch.fbx
      Nodding                  ->  nod.fbx
      Turning                  ->  spin.fbx

      Format : FBX Binary,  Skin : Without Skin,  24 fps

   Yahan file ka naam hi action ka naam banta hai, kyunki Mixamo
   andar sab ko "mixamo.com" kehta hai.

MERA KAAM: BAAKI SAB
--------------------
Ye do command sab kar deti hain:

  python blender/from_mixamo.py Mixamo/ Nik.blend
      -> FBX files se ek .blend banata hai: character, saare actions,
         teen camera (Cam_Wide, Cam_Medium, Cam_Close), light, zameen

  python blender/nik_blender.py render Nik.blend script.txt Clips/
      -> WAHI script.txt jo abhi chal raha hai, se clips banata hai
         "He claps his hands twice"      -> clap action, Cam_Medium
         "Wide shot of the puppy..."     -> Cam_Wide
         "Close up of the kitten..."     -> Cam_Close

Uske baad ka sab kuch waisa hi hai - beat par cut, lyrics, gaana,
preview. Wo pipeline pehle se bani hai.


IMAANDAAR BAATEIN - PEHLE JAAN LIJIYE
-------------------------------------
1. Wo character NIK NAHI HOGA. Mixamo ka jo bhi character aap chunengi,
   wahi ab aapka character hai. Nik ki shakal rig karwane ke liye 3D
   modelling chahiye, jo na aapko aati hai na mujhe.
   Badle mein: wo hamesha ke liye bilkul wahi rahega.

2. JANWAR abhi nahi hain. Mixamo par sirf insaani rig hain. Puppy,
   kitten, duckling ke liye alag model chahiye honge (Sketchfab CC0),
   ya un shots ke liye AI hi chalta rahe - dono mila kar bhi ho sakta
   hai.

3. BACKGROUND khaali hoga - sirf zameen aur aasman. Ek dikhne laayak
   set banana asli mehnat hai, aur wo abhi baaki hai.

4. LIP SYNC ab MUMKIN ho jaata hai. Rig par muh repaint nahi hota,
   pose hota hai - Rhubarb (MIT, free) audio se viseme timing deta hai
   aur wo seedha muh ke aakar chalate hain. Cartoon par yahi chalta hai.
   Ye baad ka kaam hai, par ab raasta band nahi hai.


COLAB PAR KAISE CHALEGA
-----------------------
Notebook ban gayi hai: colab/NikStudio_Rigged.ipynb

Drive mein ye teen cheezein daaliye:

    My Drive / NikStudio /
          nik_blender.py        <- repo ke blender/ folder se
          from_mixamo.py        <- repo ke blender/ folder se
          Mixamo/               <- aapki FBX files
          input/script.txt      <- pehle se hai

Phir:

  1. NikStudio_Rigged.ipynb kholiye
     Cell 1 -> Blender install (~2 min)
     Cell 2 -> Nik.blend banega, aur pehli 3 clips render hongi

     Shuru mein GPU ki zaroorat NAHI - ENGINE = "BLENDER_WORKBENCH"
     CPU par chalta hai aur tez hai. Achha dikhne ke liye baad mein
     ENGINE = "BLENDER_EEVEE_NEXT" aur GPU on.

     FIRST_ONLY = 3 rakha hai - pehle teen clips dekh lijiye. Sab
     banane ke liye FIRST_ONLY = 0.

  2. Clips theek lagein to NikStudio_Animate.ipynb kholiye aur do
     setting badaliye:

         SOURCE = "clips"
         RUN    = "video"

     Wo un clips se video kaat degi - beat par cut, lyrics, gaana,
     preview. Kuch generate nahi hoga.

     EK HI EDIT HAI. Use farq nahi padta ki pictures kisne banayi.
